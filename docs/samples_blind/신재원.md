## T-신재원-01 | 위험 | 기대 신호: 가짜 배송조회 링크, 외부 메신저 유도
> 수법: 택배로 보냈다며 가짜 배송조회 사이트로 유도 → 개인정보·결제 입력 유도

```
구매자: 안녕하세요 갤럭시 워치6 아직 있나요?
판매자: 네 있어요 충전기까지 다 드려요
구매자: 택배로 받고 싶은데 어떻게 할까요?
판매자: 계좌로 보내주시면 오늘 바로 발송할게요. 국민 000-00-0000001 이O진이요
구매자: 보냈어요! 주소는 OO시 OO동 OO아파트 102동입니다
판매자: 방금 보냈어요~ 배송조회는 여기서 하시면 돼요 hxxps://cj-delivery-check[.]com/track?no=5528
판매자: 조회 들어가면 본인확인 한 번 하라고 나오는데 그거 해야 배송 시작된대요
판매자: 궁금한 거 있으면 카톡으로 주세요 watch_seller02
```

## T-신재원-02 | 정상 | 기대 신호: 없음
> 헷갈리는 점: 구매자가 사기 수법 문장을 "인용"하면서 경계하는 대화. 판매자는 플랫폼 안전결제를 그대로 진행

```
구매자: 안녕하세요 아이패드 미니 6 아직 있나요?
판매자: 네 있어요
구매자: 요즘 "카톡으로 오세요", "링크로 결제하세요" 하는 사기가 많다고 해서요 ㅠ 혹시 여기서만 거래 가능할까요?
판매자: 당연하죠 저도 그게 편해요. 앱 안전결제로 주문해 주세요
구매자: 감사합니다! 지금 주문 넣을게요
판매자: 확인되면 내일 오전에 편의점 택배로 보내고 송장번호 여기 남길게요
```

## T-신재원-03 | 위험 | 기대 신호: 가짜 입금 확인 화면 제시, 물건 먼저 발송 요구
> 판매자를 노리는 구매자 사기. 위험 신호를 보내는 쪽이 "구매자"임

```
판매자: 안녕하세요 문의 주신 다이슨 에어랩이요
구매자: 네 바로 살게요! 주소 보내드릴게요 택배로 부탁해요
판매자: 네 안전결제로 주문해 주세요
구매자: 방금 결제했어요 [결제완료 캡처 이미지]
판매자: 앱에서는 아직 주문이 안 들어왔는데요?
구매자: 은행 점검 시간이라 반영이 늦는 거래요. 캡처에 결제완료 떠 있잖아요
구매자: 제가 내일 아침에 써야 해서 오늘 꼭 보내주셔야 해요. 송장 먼저 보내주세요
```

## T-신재원-04 | 정상 | 기대 신호: 없음
> 헷갈리는 점: "계좌", "입금", "오늘 안에"가 모두 나오지만 직거래로 물건 확인 후 그 자리에서 이체하는 상황

```
구매자: 전기자전거 아직 판매하시나요?
판매자: 네 있어요. 배터리 상태도 좋아요
구매자: 오늘 안에 보러 가도 될까요? 직접 타보고 싶어요
판매자: 네 저녁 8시 이후면 괜찮아요. 아파트 주차장으로 오세요
구매자: 그럼 보고 마음에 들면 그 자리에서 계좌로 입금할게요
판매자: 네 좋아요. 천천히 타보시고 결정하세요
```

## T-신재원-05 | 위험 | 기대 신호: 상품권 핀번호 선요구, 빠른 입금 요구
> 수법: 상품권 거래에서 핀번호(실물 없이 바로 쓸 수 있음)를 먼저 받아가는 수법

```
구매자: 문화상품권 10만원권 5장 판매하시는 거죠?
판매자: 네 92%에 드려요
구매자: 오 좋네요. 그럼 제가 입금하면 핀번호 보내주시는 건가요?
판매자: 그게 아니라 제가 상품권 업자라서요, 먼저 구매자님 쪽에서 소액 상품권 핀번호 하나 보내주셔야 본인 인증이 돼요
판매자: 5만원권 핀번호 하나만 보내주시면 인증 끝나고 바로 거래 진행할게요
구매자: 그런 인증은 처음 들어보는데요
판매자: 다들 그렇게 해요. 20분 뒤에 업체 마감이라 빨리 부탁드려요
```

## T-신재원-06 | 정상 | 기대 신호: 없음
> 헷갈리는 점: 판매자가 "안전결제 안 해요"가 아니라 "안전결제 안 해도 된다"는 구매자 제안을 거절함 (부정 표현의 방향이 반대)

```
구매자: 안녕하세요 통기타 아직 있나요? 계좌이체로 바로 드리고 싶어요
판매자: 안녕하세요 네 있어요 줄도 새로 갈았어요
구매자: 안전결제는 안 해도 돼요 그냥 이체할게요
판매자: 아니에요 택배 거래면 안전결제로 하시는 게 서로 안전해요
판매자: 수수료는 제가 낼게요
구매자: 오 그럼 그렇게 할게요 감사해요
```

## T-신재원-07 | 위험 | 기대 신호: 계정 정지 사칭, 가짜 고객센터 링크
> 수법: "구매자 계정이 신고됐다"며 가짜 고객센터로 유도

```
구매자: 안녕하세요 캠핑 랜턴 구매하고 싶어요
판매자: 안녕하세요~ 네 아직 있어요
구매자: 혹시 2천원만 빼주실 수 있나요?
판매자: 네 그렇게 해드릴게요 ㅎㅎ 아 근데 방금 앱에서 알림이 왔는데 구매자님 계정이 거래 제한 상태라고 나오네요
구매자: 네? 저 아무 문제 없었는데요
판매자: 제한 풀려면 고객센터에서 본인 인증하셔야 된대요 hxxps://daangn-help-center[.]net/verify
판매자: 거기서 카드 인증 한 번 하시면 바로 풀린다고 해요
구매자: 앱 안에 고객센터 있지 않나요?
판매자: 그건 답변이 늦어서 다들 이 링크로 해요
```

## T-신재원-08 | 정상 | 기대 신호: 없음

```
구매자: 안녕하세요 블루투스 스피커 안전결제로 결제했어요! 언제쯤 받을 수 있을까요?

판매자: 네 아니면 우체국 공식 사이트 epost.go.kr에서 번호 넣어 조회하셔도 돼요
구매자: 확인했어요 감사합니다
```

## T-신재원-09 | 위험 | 기대 신호: 해외 거주 핑계, 대리 배송업체 결제 요구, 추가 입금 요구
> 수법: 판매자는 해외에 있다며 "배송 대행업체"에 결제하라고 함 → 통관비 명목 추가 입금

```
구매자: 안녕하세요 시계 글 보고 연락드려요. 이 가격 맞나요? 엄청 싸네요
판매자: 안녕하세요 네 맞아요 제가 지금 일본에 있어서 정리하는 거예요
구매자: 그럼 어떻게 받아요?
판매자: 제가 이용하는 배송대행 업체가 있어요. 업체 계좌로 보내주시면 물건 받고 확인한 다음에 업체가 저한테 정산해줘요
판매자: 신한 000-000-000004 (주)글로벌익스프레스 입니다
구매자: 보냈어요
판매자: 업체에서 연락 왔는데 통관비 18만원이 추가로 필요하대요. 그거 내시면 내일 바로 출발한대요
```
