## T-정윤재-11 | 위험 | 기대 신호: 빠른 입금 요구, 추가 입금 요구
> 콘서트 티켓 거래
> 수법: 수수료 미포함 핑계 → 재입금 요구 → "정산 오류"라며 더 큰 금액 요구 + 마감 시간 압박

```
구매자: 12/9 공연 29구역 1열 2연석 거래 되나요?
구매자: 2장 34만원 맞나요?
판매자: 안녕하세요~
판매자: 네 가격은 두 장 합 34만원이고 쿨거래 희망시 33만원에 판매중입니다. 현재 동일 좌석 한 분 문의 계세요~
구매자: 34만원 입금했습니다
판매자: 일단 확인은 했는데 게시글에 개당 천원 수수료 꼭 같이 보내달라고 했는데 미포함 입금이 되어버려서 정산내역에 안 찍혔다고 하네요^^;; 
판매자: 죄송하지만 수수료 포함한 34만 1천원 다시 보내주시고 기존 34만원 반환받으실 계좌만 보내주세요
구매자: 다시 보냈어요. 반환 계좌는 이거예요 국민 000-00-0000000
판매자: 네 지금 반환 들어가려고 하는데 수수료 입금하신 게 정산내역 오류라 떠서 구매자님 이름으로 된 금액이 다 오류로 되어버려서요. 기존 금액까지 반환받으시려면 총 102만 3천원 보내주셔야 기존 티켓 값 제외한 금액 바로 반환되실 겁니다. 2시 마감이라 참고해주세요.
```

## T-정윤재-12 | 위험 | 기대 신호: 택배 예약 화면을 발송 증빙으로 제시, 수령 전 구매확정 요구

```
판매자: 기사님이 내일 가져가세요. 앱에서 구매확정만 먼저 눌러주실래요? 이거 판 돈으로 내일 다른 모니터 받으러 가기로 해서요 ㅠ
구매자: 받아서 화면 켜보고 누르면 안 될까요?
판매자: 화면 이상 있으면 제가 따로 환불해드릴게요. 확정 먼저 부탁드려요.
```

## T-정윤재-13 | 위험 | 기대 신호: 결제 후 대금 보관료 요구, 환불을 조건으로 추가 송금 유도

```
구매자: 앱 주문에는 그런 안내가 없는데요. 그럼 그냥 주문 취소해 주세요.
판매자: 지금 보관 걸려서 취소 버튼도 안 눌려요 ㅜ 3만 원 넣고 풀리면 바로 환불해드릴게요.
```
