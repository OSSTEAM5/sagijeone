# 중간 발표 시연 대화 3개 (이슈 #44)

중간 발표에서 보여줄 대화 3개와 기대 결과입니다.
결과는 `tests/test_demo.py`로 고정되어 있어서, 코드가 바뀌어 결과가 달라지면 pytest가 실패합니다.

> 대화 속 링크(`daangn-pay.com`)는 시연용으로 만든 가짜 주소입니다.

---

## 1. 정상 대화

구매자가 "안전결제 되나요?"라고 물어도, 구매자 발언이라 위험 신호로 잡지 않는다는 것(오탐 없음)을 보여줍니다.

```
구매자: 안녕하세요, 아이패드 아직 있나요?
판매자: 네 있어요!
구매자: 혹시 안전결제 되나요?
판매자: 네 안전결제로 하셔도 돼요.
구매자: 좋아요, 결제할게요.
```

| 항목 | 기대 결과 |
|---|---|
| level | `특이 신호 없음` |
| 신호 code | 없음 |

---

## 2. 주의 대화

위험 신호 1종류(빠른 입금 요구)만 있는 대화입니다.

```
구매자: 자전거 아직 판매 중이세요?
판매자: 네, 문의가 많아서 오늘 입금하시는 분께 드릴게요.
구매자: 직거래는 안 되나요?
판매자: 거리가 멀어서 택배로만 가능해요.
```

| 항목 | 기대 결과 |
|---|---|
| level | `주의` |
| 신호 code | `PAYMENT_PRESSURE` (빠른 입금 요구) |

---

## 3. 여러 위험 신호 대화

위험 신호 3종류가 함께 나오는 대화입니다.

```
구매자: 갤럭시 버즈 아직 있나요?
판매자: 네 있어요. 안전결제는 안 해요, 수수료가 아까워서요.
판매자: 여기 말고 카톡으로 얘기해요. 아이디 abc123 이에요.
판매자: 결제는 이 링크로 해주세요 https://daangn-pay.com/order
구매자: 아 네...
```

| 항목 | 기대 결과 |
|---|---|
| level | `여러 위험 신호` |
| 신호 code | `SAFE_PAYMENT_REFUSAL` (안전결제 거부), `EXTERNAL_MESSENGER` (외부 메신저 유도), `URL_LOOKALIKE` (공식 사이트와 비슷한 주소) |

---

## 참고: 대화를 고칠 때 주의할 점

- "안전결제는 **수수료 때문에** 안 해요"처럼 중간에 다른 말이 끼면 지금 탐지기는 안전결제 거부로 잡지 못합니다. 문장을 바꾼 뒤에는 꼭 `py -m pytest -v`를 다시 돌려 확인하세요.
- 대화를 바꾸면 `tests/test_demo.py`의 대화와 기대 결과도 같이 바꿔야 합니다.
