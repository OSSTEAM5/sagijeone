# 사기전에 🔍

> **사기 전에, 한 번 더 확인하세요.**

중고거래 채팅·판매글·스크린샷·URL을 분석해서 **거래의 위험 신호를 근거와 함께 알려주는** 웹 서비스입니다.

「오픈소스SW프로그래밍」 팀 프로젝트

---

## 무엇을 하나요?

사용자가 중고거래 대화 내용을 붙여넣거나 스크린샷을 올리면, 여러 위험 신호를 함께 분석해서 알려줍니다.

```
⚠️ 주의 필요

발견된 위험 신호
1. 안전결제 거부       — "안전결제는 수수료 때문에 안 해요"
2. 빠른 입금 요구      — "오늘 안에 입금하시면 바로 보내드려요"
3. 외부 메신저 이동    — "카톡 아이디 알려드릴게요"

권장 행동
- 플랫폼 안전결제를 요청하세요
- 입금 전 계좌번호 신고 이력을 확인하세요
```

## 원칙

- **판매자를 사기꾼이라고 단정하지 않습니다.** 무엇이, 왜 위험 신호인지 근거를 보여주는 것이 목적입니다 (Explainable Risk Analysis).
- **하나의 키워드만으로 판단하지 않습니다.** 여러 신호가 함께 나타나는지를 봅니다.
- **정상 거래를 위험하다고 판단하는 오류(False Positive)를 줄이는 것을 중요하게 생각합니다.** 예를 들어 화자와 부정 표현("안전결제도 가능합니다")을 고려합니다.

## 기능 로드맵

| 단계 | 기능 | 상태 |
|---|---|---|
| MVP | 채팅 텍스트 입력 → 규칙 기반 위험 신호 탐지 → 근거 표시 | ⬜ |
| MVP | 웹 페이지 + 배포 (URL로 접속 가능) | ⬜ |
| 2차 | 스크린샷 OCR 입력 (추출 텍스트 수정 가능) | ⬜ |
| 2차 | URL 분석 (유사 도메인, 단축 URL 등) | ⬜ |
| 확장 | 가격 시세 비교 | ⬜ |
| 확장 | 전화번호/계좌번호 신고 이력 조회 (데모: Mock Data) | ⬜ |

## 구조

```
사용자 → 웹페이지 → Backend API
                     ├ 입력 처리 (OCR, 텍스트/URL/번호 추출)
                     ├ 분석기(detectors)  ← 함수 리스트로 관리 (Strategy Pattern)
                     └ Risk Engine → 결과
```

```
backend/    # API 서버, 분석기, Risk Engine
frontend/   # 웹 화면
tests/      # 테스트 (정상/위험/헷갈리는 대화 샘플 포함)
docs/       # 회의록 외 문서, 설계 자료
```

> 기술 스택과 폴더 구조는 킥오프 회의에서 확정 후 업데이트합니다.

## 기술 스택 (예정)

- Backend: Python, FastAPI
- OCR: EasyOCR
- Frontend: HTML/CSS/JS (미정)
- 배포: Docker, Render
